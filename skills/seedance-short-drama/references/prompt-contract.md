# Seedance 短剧提示词契约

本文件是 `shot-prompt`、`batch-package`、`edit-extend` 和 `prompt-review` 模式的共同规范。它约束提示词如何表达，不假定某个入口永远支持固定的上传数量或分辨率。

## 1. 最小字段

每个镜头应能回答以下问题：

| 字段 | 必答问题 |
| --- | --- |
| `shot_id` | 这是哪一场、哪一镜？ |
| `dramatic_goal` | 观众在本镜头结束时应感受到或知道什么？ |
| `duration` | 目标秒数是多少？ |
| `start_state` | 第一帧人物、道具、位置、表情和光线是什么？ |
| `end_state` | 最后一帧要停在哪里，供下一镜头接什么？ |
| `subject_action` | 谁按什么顺序做什么？ |
| `camera` | 景别、机位、路径、速度、焦点和结束状态是什么？ |
| `audio` | 对白、旁白、BGM、环境声和动作音效是什么？ |
| `references` | 每个 `@` 素材具体参考哪一个维度？ |

缺少 `start_state` 或 `end_state` 时，提示词仍可写，但必须在假设区标明，批量生产时优先补齐。

## 2. 素材引用协议

先建立一份映射，再写正文：

```text
@图片1：角色 A 的当前造型与面部特征；只用于人物一致性
@图片2：雨夜巷道的场景和光线；只用于背景与色温
@视频1：手持跟拍的路径、速度和停顿；不复制人物、剧情、文字或声音
@音频1：BGM 的节奏密度；不复制原录音或歌词
```

最终提示词只使用已经登记的 ID。一个素材可承担多个职责，但要分开写明；如果素材只用于筛选、未进入提示词，登记为“弃用”。

避免以下模糊写法：

- `参考 @视频1`（没有说明参考什么）；
- `完全复刻 @视频1`（没有限定身份、剧情、文字和版权范围）；
- `图片1`、`@图1`、`@图片1` 混用；
- 使用不存在的 `@视频` 或 `@音频` ID。

## 3. 时间轴写法

使用半开区间，最后一段包含结束画面：

```text
总时长：8.0s
0.0–2.0s：中近景，角色 A 站在门内，听见门外敲门声，眼神从放松转为警觉；镜头慢慢向前推。
2.0–5.5s：镜头保持同一轴线跟随 A 走到门边；A 的右手握住门把，停顿半秒，不开门。
5.5–8.0s：切到门外的低角度近景，门缝透出冷光；A 只露出一只眼睛，画面停在敲门声的余韵上。
```

规则：

- 所有区间首尾相接，不重叠、不留空白；
- 每段写可观察动作和镜头状态；
- 时间越短，动作越少；不要在 3 秒内同时安排奔跑、转身、取物、对白和复杂变身；
- 需要快切时明确“切点”和“切后状态”，不要同时要求“一镜到底”。

## 4. 镜头和动作表达

镜头字段至少包括：

```text
景别：中近景
机位：角色右前方，与视线同高
运动：缓慢前推 0.8 米，速度均匀
焦点：先锁定眼睛，手握门把时转移到手部，再回到眼睛
轴线：保持角色朝画面右侧，不能越过 180° 轴
结束：停在角色尚未开门的警觉表情
```

动作字段使用“主体 + 动词 + 方向/力度 + 接触物 + 结果”：

```text
角色 A 用右手握住门把，先施加很小的力度，听见第二声敲门后松手，手停在门把上方。
```

抽象词可以作为情绪补充，但不能代替动作：

- 不推荐：`自然地表现紧张`；
- 推荐：`呼吸变浅，肩膀略抬，视线在门把和猫眼之间快速移动`。

## 5. 对白、声音和屏幕文字

对白格式：

```text
对白：角色 A（压低声音、语速慢、说到最后一个字停顿）：“别开门。”
口型：与普通话对白同步，避免额外台词。
```

声音按层写：

```text
BGM：低音弦乐，持续但不抢对白；对白进入时自动降低。
环境声：雨声、远处车辆，持续贯穿全镜头。
动作音效：门外两次敲门、门把轻响，分别落在 1.2s 和 3.8s。
```

关键字幕、品牌名、电话号码等精确文字不要依赖模型直接生成。提示词中给出内容和出现时刻，同时在交付清单中建议后期叠字。
- 没有 BGM 时仍写 `BGM：无`；尚未决定时写 `BGM：待定`，并把它列入待确认项。
- 会触发剧情转折的录音、短信、证据或旁白必须给出原文或明确占位符（如 `[录音原文待提供]`），否则该转折不可验收。

## 6. 可复制提示词模板

```text
制作一段 [时长] 的 [画幅/用途] 短剧镜头，镜头编号 [shot_id]。
主体与场景：[人物身份、当前造型、场景、时间、天气、光线]。
素材用途：[逐项写 @ID 的职责，限定只参考哪些维度]。
起始状态：[第一帧可见的站位、表情、道具状态]。
[时间段 1]：[动作、表演、景别、机位、运镜、焦点、声音]。
[时间段 2]：[动作、表演、景别、机位、运镜、焦点、声音]。
结束状态：[最后一帧和下一镜头需要继承的状态]。
对白/旁白：[角色、原文、语气、口型要求]。
音频：[BGM、环境声、动作音效及混音关系]。
视觉风格：[色彩、材质、光影、帧率或其他确有必要的风格约束]。
约束：保持 [身份/服装/道具/轴线/视线] 连续；不要新增角色、台词、文字或未授权素材。
```

## 7. 版本约束的处理

只在用户提供了当前入口的限制，或能读取可信的最新平台文档时，把数量、格式、大小、输入时长和输出档位写成硬检查。否则使用以下表述：

```text
平台参数：按当前 Seedance 入口确认；本提示词不假设固定上传上限。
```

延长视频时，明确“原片保留段”和“新增段”，并以新增段的起始画面作为连续性锚点；不要把总片长和新增时长混为一谈。
