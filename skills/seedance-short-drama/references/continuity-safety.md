# 连续性与安全质检

本文件用于 `batch-package`、`continuity-patch`、`edit-extend` 和含真实人物、危险动作或版权素材的任务。

## 1. 全局连续性账本

批量输出前建立并持续更新以下字段。只记录会影响画面或声音的状态，不复制整段剧本。

| 类别 | 记录方式 |
| --- | --- |
| 人物 | 角色 ID、年龄段、发型、服装、主色、伤痕/妆容、当前情绪 |
| 站位与方向 | 进入画面方向、屏幕左右、朝向、运动方向、轴线 |
| 道具 | 道具 ID、持有者、左右手、开合/破损/电量/内容物状态 |
| 场景 | 时间、天气、灯光方向、色温、背景层次和可见文字 |
| 镜头 | 上一镜尾帧、下一镜首帧、景别、焦点、运动连续性 |
| 声音 | BGM 段落、环境底噪、动作音效、对白/旁白状态 |
| 参考素材 | 来源、授权状态、已锁定用途、禁止复制的内容 |

每次改动只更新受影响的字段，并在交付中写出“继承自上一镜头 / 修改为本镜头”的差异。

## 2. 连续性检查顺序

按以下顺序检查，先处理会使镜头无法接上的问题：

1. 角色身份、脸部可识别特征、发型和服装是否一致；
2. 道具是否在正确的手、正确的开合/损坏状态；
3. 屏幕方向、视线和 180° 轴是否保持，除非明确设计越轴；
4. 光源方向、时间、天气和场景入口是否连续；
5. 动作是否从上一镜头的结束姿态自然开始，并在本镜头结束时形成可接状态；
6. BGM、环境声和对白是否在切点处连续或有意断开。

如果无法同时满足连续性和用户的新要求，保留用户明确要求，并把冲突标成阻塞项，不要静默改写。

## 3. 真实人物、声音与版权

- 需要真人脸或真人声音时，确认用户有权使用，并避免把生成结果包装成真实事件或真实人物的原话。
- 对公众人物、未成年人、私密人物或可识别个人，默认提高审查等级；可以建议使用虚构角色、非识别化形象或授权素材。
- 参考视频、音乐、字体、品牌包装和影视片段只在授权范围内使用。提示词应限定“参考节奏/构图/材质”等抽象维度，不要求逐帧复制受保护内容。
- 不能通过改名、裁切、去水印或“完全复刻”来规避平台、版权或身份限制。
- 用户没有给出授权状态时，写入“授权待确认”，不要替用户推定有权。

## 4. 危险动作与敏感内容

对坠落、溺水、火灾、武器、打斗、窒息、交通事故和自伤等内容：

- 先确认戏剧目的，再把动作拆成可控的非伤害性可视结果；
- 避免提供现实可执行的伤害步骤、弱点或操作细节；
- 明确镜头表现的是虚构表演，必要时采用遮挡、反应镜头、声音和剪辑暗示结果；
- 标注需要人工安全审查的镜头，不承诺平台一定通过。

含未成年人、性内容、极端血腥、仇恨或真实犯罪指向时，暂停生成具体可执行提示词，改为安全的叙事替代方案或请求人工审查。

## 5. 生产验收等级

把问题分为三档：

- **阻塞**：缺少关键素材、引用悬空、时长区间不闭合、人物/道具无法接续、存在明显权利或安全问题。不得标记为可生产。
- **警告**：动作过密、台词过长、字幕可能乱码、音画层级冲突、平台参数未确认。可以交付草案，但需写明风险。
- **建议**：风格词过多、镜头可进一步简化、音效层次可优化。允许带入下一轮迭代。

最终结论只使用以下词汇之一：`可生产`、`需修订`、`阻塞待确认`。不要使用“完全保证”“零风险”“百分百还原”。

## 6. 生成后复盘

Seedance 生成结果出来后，用同一账本复核：身份、动作、手部、道具、口型、屏幕方向、文字、音画同步和首尾帧。每次返工只修改一个主要变量，并记录“问题 → 假设原因 → 改动 → 结果”，避免一次加入大量新指令。
